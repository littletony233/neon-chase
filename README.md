# NEON CHASE / 霓虹追缉

A cute cyberpunk police-and-thief runner. One thief, one very theatrical cop, one endless neon city.

**Play:** https://littletony233.github.io/neon-chase/

[![Scan to play](qr-card.png)](https://littletony233.github.io/neon-chase/)

## Controls

- Left / Right or A / D — change lane
- Up / W / Space — jump
- Down / S — slide
- E — dash (3 s, invulnerable)
- P / Esc — pause
- Touch: swipe, or use the on-screen buttons

## About

The whole game is one self-contained HTML file: canvas art, music and sound effects are embedded. It runs offline and on a phone; no server or install is required.

Game code, vector characters, city, UI and the eight synthesized sound effects were generated with Claude Code and directed/edited by the student. Background music: **Jairo - FLASH**, supplied by the student; confirm licence and attribution before public release. No external sprites, images or web fonts are bundled.
